# chaosxedu
ChaosX — платформа для школьной математики для 5–11 классов. Директор заводит школу и группы, учитель выдаёт работы и ведёт журнал, ученик решает задачи в браузере.

Здешние скрипты собраны вокруг одного сюжета — как результат ученика становится отметкой в журнале и строкой в выгрузке для завуча — и дополнены двумя файлами, по которым видно, как этот сюжет вписан в платформу.

Читать удобнее всего в следующем порядке: xlsx.py -> grading.py -> journal.py -> journal_export.py -> deps.py; первые два понятны без остального кода.
